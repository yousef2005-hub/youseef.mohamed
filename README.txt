موقع Portfolio شخصي - يوسف محمد المرسي محمد

الملفات:
- index.html: محتوى الموقع.
- style.css: تنسيق وتصميم الموقع.

طريقة التشغيل:
1. فك ضغط الملف ZIP.
2. افتح index.html باستخدام متصفح الإنترنت.
3. يحتاج Bootstrap والخط الخارجي إلى اتصال بالإنترنت لتحميلهما.

التعديل:
- لتغيير البريد الإلكتروني، ابحث في index.html عن your.email@example.com واستبدله ببريدك.
- عدّل قسم المهارات والمشاريع لتطابق مستواك وأعمالك الحقيقية.
- صورة الملف الشخصي الحالية عبارة عن حروف أول الاسم، ويمكن استبدالها بصورة شخصية إذا رغبت.

التقنيات: HTML5، CSS3، Bootstrap 5 RTL، JavaScript بسيط لقائمة الهاتف.
